# Flying Limo

Marketing website for Flying Limo — luxury chauffeured transportation across the San Francisco Bay Area.

## Structure

- `index.html` — homepage
- `blog.html` — blog listing
- `blog/` — individual blog posts
- `css/style.css` — site styles
- `js/main.js` — nav, scroll-reveal, and misc behavior
- `assets/` — logo, fleet photos, hero photo, blog photos

## Running locally

This is a static site with no build step. Serve the directory with any static file server, e.g.:

```bash
python3 -m http.server 8934
```

Then open `http://localhost:8934/index.html`.
